# **🌟 Saim Cis 🌟**

[![Website](https://img.shields.io/badge/Visit-Website-blue)](http://saimcis.vercel.app)

SAIM CIS es una aplicación web innovadora que reduce el tiempo de atención a los pacientes mediante la gestión eficiente de citas, consultas y expedientes médicos digitales. Nuestra solución ofrece a los pacientes una plataforma intuitiva donde pueden ver y solicitar citas con el especialista de su preferencia en horarios que se adapten a sus necesidades.

## 🌐 [Visita nuestro sitio web](http://saimcis.vercel.app)

## 📋 Funcionalidades principales

A continuación se muestran las funcionalidades de nuestra aplicación por tipo de usuario:

### 👥 *Pacientes:*

- Visualización de todas las citas programadas.
- Visualización de médicos y especialistas disponibles.
- Solicitud de nuevas citas.
- Cancelación y/o solicitud para reagendar citas.

### 🩺 *Doctores:*

- Visualización del historial médico de cada paciente.
- Generar consultas.
- Brindar un diagnóstico.

### 🏥 *Enfermeros:*

- Crear y actualizar expedientes.
- Ingresar signos vitales (preclínica).
- Editar perfil de usuarios pacientes.

### 🛠️ *Administradores:*

- Registrar enfermeros, doctores, pacientes y otros administradores.
- Modificar perfiles de cualquier tipo de usuario.
- Gestionar permisos y roles de usuarios.

¡Explora más sobre nuestra plataforma y cómo puede ayudarte a gestionar eficientemente tus necesidades médicas en [SAIM CIS](http://saimcis.vercel.app)!
